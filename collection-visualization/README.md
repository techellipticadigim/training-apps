# Collection Visualization - Interactive Data Structures

An interactive educational web application that demonstrates the internal storage and behavior of common data structures and collections.

## Structure

This application is modularized with separate HTML pages for each data structure:

### Pages Created

1. **index.html** - Landing page with links to all data structures
2. **array.html** - Fixed-size array visualization
3. **arraylist.html** - Dynamic array with resizing
4. **linkedlist.html** - Singly and doubly linked lists
5. **hashset.html** - Hash table-based set
6. **hashmap.html** - Key-value hash table
7. **stack.html** - LIFO stack
8. **queue.html** - FIFO queue
9. **bst.html** - Binary Search Tree
10. **heap.html** - Min/Max heap

### Remaining Pages (Basic implementations)

- **linkedhashset.html** - HashSet with insertion order
- **treeset.html** - Balanced BST set
- **linkedhashmap.html** - HashMap with insertion order
- **treemap.html** - Sorted key-value map
- **deque.html** - Double-ended queue
- **avl.html** - Self-balancing AVL tree
- **graph.html** - Graph with adjacency list/matrix

## Files

- `styles.css` - Shared CSS styles
- `utils.js` - Shared JavaScript utilities and base classes
- Each data structure has its own HTML file with embedded JavaScript

## Features

- Interactive visualizations
- Memory view toggle
- Step-by-step animations
- Complexity information
- Code snippets
- Example inputs
- Dark/Light theme
- Export to JSON

## Usage

1. Open `index.html` in a web browser
2. Click on any data structure to explore it
3. Use the control panel to perform operations
4. Toggle memory view and details as needed

## Browser Support

Modern browsers with ES6+ support (Chrome, Firefox, Safari, Edge)
